# UI Overview

This section covers design tokens, component patterns, and user-experience rules for the Angular frontends.

- [`components_and_patterns.md`](components_and_patterns.md)

- [`experience.md`](experience.md)

- [`standards.md`](standards.md)
  - Current visual, interaction, accessibility, and responsive implementation standards.

## Reading Guidance

- Read [`design_tokens.md`](design_tokens.md) when changing typography, spacing, or color decisions.
- Read [`components_and_patterns.md`](components_and_patterns.md) when editing controls, forms, panels, or dialogs.
- Read [`experience.md`](experience.md) when reviewing page behavior, responsive layout, accessibility, or workflow UX.
- Read [`standards.md`](standards.md) when implementing or reviewing current UI polish and interaction standards.
