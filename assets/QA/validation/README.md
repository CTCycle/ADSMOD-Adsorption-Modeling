# Retained validation evidence

Last updated: 2026-09-30

Current validation status, durable decisions, limitations, and revalidation
paths live in [`assets/docs/project_status_ledger.md`](../../docs/project_status_ledger.md).
Stable slice scope and evidence rules live in
[`assets/docs/validation/roadmap.md`](../../docs/validation/roadmap.md).

This directory is an evidence vault, not a second status catalog. Keep it
sparse: retain only a rendered capture, provider response, or raw run artifact
that is needed to support a current claim and cannot be reproduced from source
tests, generated contracts, or hosted CI. Link retained artifacts from the
ledger or the relevant concept document.

Do not add duplicate screenshots, generated contract copies, raw logs, helper
scripts, or per-run narrative reports when the underlying repository test or
hosted run is already the durable evidence. Do not store secrets or tokens.
Historical evidence consolidated during the 2026-09-30 documentation cleanup
remains available in Git history rather than as a parallel current-status tree.
